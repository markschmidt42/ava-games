# Pass the Pigs — reference photos

Photos of the real pig set and the scoring card from the box, for use as art
reference when building the game.

| File | What it shows |
| --- | --- |
| `scoring-card.jpg` | Official scoring card — all seven outcomes and point values |
| `pigs-01.jpg` – `pigs-08.jpg` | The two pigs in assorted resting positions, photographed from a few angles |

## Scoring, transcribed from the card

| Outcome | Points |
| --- | --- |
| Sider (both pigs on the same side) | 1 |
| Razorback (on its back) | 5 — Double 20 |
| Trotter (standing on all four feet) | 5 — Double 20 |
| Snouter (leaning on snout and front feet) | 10 — Double 40 |
| Leaning Jowler (on snout, ear, and one foot) | 15 — Double 60 |
| Pig Out (pigs on opposite sides) | Lose points for your turn |
| Oinker (pigs touching) | Back to zero |

Mixed positions score the sum of the two pigs.

Position labels for `pigs-01` through `pigs-08` aren't assigned yet — the poses
are easier to name with the pigs in hand than from the photos.
